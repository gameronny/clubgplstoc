# ClubGPLStock

ClubGPLStock is a Python-based application for stock developed as part of my Software Engineering learning process.
The project focuses on basic application logic, data handling, and simple stock management features.

## Features
- Core application logic implemented in Python
- Database handling for storing and retrieving data
- Stock management functionality
- Modular project structure for better maintainability

## Project Structure
- `main.py` – application entry point
- `database.py` – database connection and data handling logic
- `stock_window.py` – stock management interface and logic

## Technologies Used
- Python
- SQLite (or local database storage)
- GitHub for version control
